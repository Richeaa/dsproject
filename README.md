# 🤖 Machine Learning Web Application (Django-Based)

This is a Django-based web application developed as a **final exam project**. The project integrates machine learning models into a user-friendly web interface that allows users to input data and receive predictions based on historical trends.

## 🎯 Project Objective

To build a predictive system that enables users to forecast different kinds of cases (e.g., classification or regression tasks) using pre-trained machine learning models — deployed within a Django web app.

## 💡 Key Highlights

1. **🔬 Machine Learning Model Development**  
   - Trained multiple models using algorithms such as **Random Forest**, **XGBoost**, and others.
   - Tuned hyperparameters and validated model performance with real-world datasets.

2. **🌐 Django Web Application**  
   - Implemented a full-stack web app with **Django**, integrating the trained ML model.
   - Enabled users to **input custom data** and get live predictions with interactive UI.

3. **📊 Data Visualization & Evaluation**  
   - Incorporated **Chart.js** for displaying prediction results and model performance visually.
   - Assessed models using metrics like:
     - Classification: Accuracy, Precision, Recall
     - Regression: Mean Squared Error (MSE), R² Score

## 🚀 Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS, Bootstrap
- **Data Visualization**: Chart.js
- **Machine Learning**: scikit-learn, XGBoost, pandas, NumPy
